Operational Notes

  • For VM 104, database values are generated after installation in /opt/e-SUS/webserver/config/credenciais.txt. Read them only for direct Infisical entry.
  • The credential file on VM 104 was set to root:root mode 600.
  • For CT 133, database values are generated after installation in /opt/e-SUS/webserver/config/credenciais.txt. Read them only for direct Infisical entry under the approved /test folder.
  • The credential file on CT 133 was set to root:root mode 600.
  • On 2026-06-01, the first-run installation variables were confirmed by name in Infisical project esus-pec, environment dev, folder /test/InstallationConfig; values were not copied to Git or docs.
  • On 2026-06-05, the post-install configuration variable names above were collected from the PEC UI and front-end GraphQL bundle. No PEC configuration was changed.
  • Base-unification credentials require an HTTPS PEC session; only high-level desired-state variables are documented until TLS is available.
  • On 2026-06-05, CT 133 was configured with a self-signed TLS certificate and nginx reverse proxy on port 443. Certificate PEM, private key PEM, HTTPS URL, fingerprint, SAN, expiration, certificate kind, and termination mode were stored in Infisical environment dev, folder /test/InstallationConfig.
  • On 2026-06-05, Infisical variable reconciliation was prepared with scripts/esus-pec/Sync-EsusPecInfisicalVariables.ps1. Runtime values target /test; installation values target /test/InstallationConfig; no secret values were printed. Non-dry-run apply is blocked until the token can create/delete directly at /test.
  • CT 133 requires RemoveIPC=no in /etc/systemd/logind.conf.d/99-esus-pec-postgresql.conf before the first PEC installer run.
  • ESUS_PEC_ADMIN_USERNAME and ESUS_PEC_ADMIN_PASSWORD were reported as already filled by the operator.
  • VM 101 must remain read-only unless a future instruction explicitly changes that constraint.
  • CT 100 NetBird must not be restarted or reconfigured during PEC testing.
  • Store real secret values only in Infisical, never in *.example, Markdown, logs, or Git history.
