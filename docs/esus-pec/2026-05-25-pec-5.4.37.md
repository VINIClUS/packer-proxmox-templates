## Safe Handling Rules

- Do not execute the installer during read-only discovery.
- If the Linux installer is downloaded, store it in a controlled staging path
  and record local path, byte size, and SHA-256.
- Treat installer execution, service stop/start, database restore, disk resize,
  nginx reload, and firewall changes as approval-gated operations.
- Prefer console/headless install if supported; use X11 only as a fallback after
  documenting why headless mode is unavailable.
