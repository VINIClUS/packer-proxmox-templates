# e-SUS PEC LXC TLS Implementation

## Scope

Implemented TLS for CT `133 esus-pec-lxc-5437` at `192.168.1.209` without modifying VM `101 ESUS-TESTE` or CT `100 NetBird`.

The PEC Java service remains on `0.0.0.0:8080`. TLS is terminated by `nginx` inside CT `133` on port `443` and proxied to `http://127.0.0.1:8080`.

## Implementation

The reusable script is:

```powershell
rtk powershell -NoProfile -ExecutionPolicy Bypass -File scripts/esus-pec/Enable-EsusPecLxcTls.ps1
```

It reads Proxmox SSH settings from `config/Proxmox.pkrvars.hcl`, executes commands through `pct exec 133`, and stores TLS material in Infisical. The script is idempotent: it reuses `/etc/esus-pec/tls/tls.crt` and `/etc/esus-pec/tls/tls.key` unless `-ForceRotateCertificate` is passed.

Only one package set was added to the CT when missing:

```text
nginx ca-certificates
```

No PostgreSQL-related packages were installed.

## Rollback

To disable TLS termination while leaving PEC HTTP intact:

```bash
pct exec 133 -- systemctl disable --now nginx
```

To remove the TLS files after confirming Infisical has the desired copy:

```bash
pct exec 133 -- rm -rf /etc/esus-pec/tls /etc/nginx/sites-enabled/esus-pec-tls.conf /etc/nginx/sites-available/esus-pec-tls.conf
```

Do not delete or rotate the Infisical TLS secrets until the replacement certificate is deployed and validated.
