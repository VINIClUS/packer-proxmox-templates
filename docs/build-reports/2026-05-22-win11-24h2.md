## SDN Permission Retry

After `SDN.Use` was granted on `/sdn/zones/localnetwork/vmbr0`, Packer created
and started VM `9101`, uploaded the generated answer ISO, and reached the
Windows installer.

Console validation showed the first installer blocker was:

```text
Install driver to show hardware
```

The VM had the Windows and VirtIO ISOs attached as SCSI CD-ROMs:

```text
boot  : order=scsi1;ide0;scsi0
scsi1 : local:iso/win11_24H2_english_x64.iso,media=cdrom
scsi2 : local:iso/virtio-win.iso,media=cdrom
```

The template now attaches both installer media ISOs as SATA CD-ROMs and boots
with `order=sata0;ide0;scsi0`, keeping the system disk on VirtIO SCSI.

The next console validation passed the media-driver screen and reached the
Windows product-key page. The answer file now injects `windows_product_key`
so setup can remain unattended.

The following retry passed the product-key page and stopped at image selection.
Console validation showed the uploaded ISO contains:

```text
Windows 11 Enterprise
Windows 11 IoT Enterprise
Windows 11 IoT Enterprise Subscription
```

The template defaults now target `Windows 11 Enterprise` and use the public
Windows 11 Enterprise setup key. This key does not activate Windows.
